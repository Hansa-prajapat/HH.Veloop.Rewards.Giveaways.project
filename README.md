# VELOOP Rewards & Giveaways — Premium UI

A Vite + React demo for a premium dark Watch & Earn rewards dashboard.

## Features
- Premium dark blue / purple gradient UI
- Watch & Earn with 6 ad cards
- Loading, countdown, progress and reward-success flow
- Daily bonus, daily progress and recent activity
- Weekly leaderboard and gift rewards
- Profile page with separate navigation
- Winner Gift Entry form and saved gift-processing status
- Rewards center and demo wallet
- Responsive layout
- localStorage demo persistence

## Run locally
```bash
npm install
npm run dev
```
Then open the local Vite URL shown in the terminal.

## Build
```bash
npm run build
npm run preview
```

## Netlify / Vercel
Build command: `npm run build`
Publish/output directory: `dist`
No environment variables are required for this frontend demo.

## GitHub upload structure
Upload the CONTENTS of this folder to the root of the repository. The repository root should contain `index.html`, `package.json`, `vite.config.js`, `public/`, and `src/` directly.

## New How It Works & Eligibility / Safety sections
- **How It Works** explains the demo journey: watch an eligible ad, receive VE points, climb the leaderboard, and process a winner gift entry.
- **Eligibility & Safety** explains that real reward/giveaway eligibility must follow published terms and age requirements, while the included app is a frontend demo using sample/local browser data.
- Safety guidance reminds users not to enter passwords, bank details, OTPs, or other sensitive information into the demo.
- The demo does not guarantee real cash, prizes, or delivery; a real deployment would require a verified backend, reward provider, terms, privacy controls, and fulfilment process.
